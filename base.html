Installez l'application sur votre téléphone

🍎 Sur iPhone / iPad (Safari)

  1. Ouvrez cette page dans Safari
  2. Appuyez sur Partager ⎙
  3. Choisissez « Sur l'écran d'accueil »
  4. Confirmez avec Ajouter

🤖 Sur Android (Chrome) — méthode manuelle

  1. Appuyez sur le menu ⋮ en haut à droite
  2. Choisissez « Ajouter à l'écran d'accueil »
  3. Confirmez avec Ajouter
