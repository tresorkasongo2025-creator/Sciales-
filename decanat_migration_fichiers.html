⬆️ Importer les fichiers depuis un ZIP

Créez un ZIP sur votre machine de développement contenant les répertoires suivants, puis uploadez-le ici. Les fichiers existants seront remplacés silencieusement.

📋 Comment créer le ZIP sur votre machine de dev

Structure attendue dans le ZIP :

mon_export.zip
├── uploads/          ← photos étudiants (*.jpg, *.png, *.jpeg)
│   ├── ETU000001_photo.jpg
│   └── ...
├── qrcodes/          ← QR codes (*.png)
│   ├── ETU000001.png
│   └── ...
├── horaires/         ← horaires (*.pdf, *.jpg, *.png)
│   └── RI_BAC_2_normal_...pdf
└── actualites/       ← images actualités (*.jpg, *.png)
    └── 20251103_...jpg

Commande Linux/Mac :

cd /chemin/vers/votre/projet
zip -r mon_export.zip static/uploads static/qrcodes static/horaires static/actualites \
    --junk-paths \
    -x "*/.*"
# Ensuite renommez les répertoires dans le ZIP si nécessaire
# OU utilisez cette commande qui garde la bonne structure :
zip -r mon_export.zip uploads/ qrcodes/ horaires/ actualites/ \
  -i "uploads/*" -i "qrcodes/*" -i "horaires/*" -i "actualites/*"

Script Python plus simple :

import zipfile, os

folders = ['uploads', 'qrcodes', 'horaires', 'actualites']
with zipfile.ZipFile('mon_export.zip', 'w', zipfile.ZIP_DEFLATED) as zf:
    for folder in folders:
        src = os.path.join('static', folder)
        for fname in os.listdir(src):
            fpath = os.path.join(src, fname)
            if os.path.isfile(fpath):
                zf.write(fpath, arcname=f'{folder}/{fname}')
print('ZIP créé : mon_export.zip')

⚠️ Le ZIP doit contenir les sous-répertoires uploads/, qrcodes/, horaires/ et/ou actualites/ directement à la racine. Seules les extensions .png .jpg .jpeg .pdf sont acceptées.

Taille maximale : 16 Mo. Pour des volumes plus importants, utilisez le terminal Replit.

ℹ️ Persistance des fichiers sur ce serveur

L'application tourne sur une VM Réservée avec un système de fichiers persistant. Les fichiers uploadés (photos, QR codes, horaires, actualités) survivent aux redémarrages et aux redéploiements — ils ne sont jamais effacés automatiquement.

Une migration est uniquement nécessaire lors du passage initial de l'environnement de développement vers la production, ou après un changement de serveur.
